# AIToolSender — شرح النظام الكامل بالعربية

نظام SaaS لاكتشاف العملاء المحتملين بالذكاء الاصطناعي وإرسال رسائل تواصل مخصّصة
بجودة عالية — **الجودة قبل الكمية** (10–50 عميلًا في اليوم، وليس إرسالًا جماعيًا).

---

## 1. الفكرة الأساسية

معظم أدوات التواصل البارد تراهن على **الكمية**: إرسال آلاف الرسائل وانتظار نسبة رد
ضئيلة — وهذا يحرق سمعة الدومين ويخالف القوانين (CAN-SPAM / GDPR). هذا النظام يراهن
على العكس: **عدد قليل من العملاء المدروسين جيدًا + رسائل مخصّصة حقًا** تتفوّق على
آلاف الرسائل النمطية. لذلك كل النظام مصمَّم لإنفاق الحوسبة في إيجاد العملاء
**المناسبين** وكتابة رسائل تبدو وكأن إنسانًا كتبها بعد الاطلاع على موقع الشركة.

**قرار جوهري:** الإرسال لا يتم تلقائيًا بالكامل. الوكيل يعمل ليلًا وينفّذ كل شيء
**حتى الإرسال**، ويترك الرسائل بحالة "بانتظار الموافقة". أنت توافق بنقرة واحدة، ثم
يُرسَل النظام بشكل مُنظَّم. هذا يحمي سمعة الدومين ويُبقيك ضمن القانون. (يمكن تفعيل
الإرسال التلقائي الكامل لكل حملة بعد تهيئة الدومين.)

## 2. كيف يعمل — المسار من 8 خطوات

| الخطوة | ماذا تفعل |
|---|---|
| 1) التحليل | الذكاء الاصطناعي يقرأ المنتج ويستخرج: ملخّصًا، فوائد، صناعات، نوع الجمهور (B2B/B2C)، نقاط الألم، **ملفات العملاء المثاليين (ICPs)** وزوايا التواصل. |
| 2) الاكتشاف | بحث مستهدف عن الشركات الأكثر احتمالًا للشراء (عبر Serper.dev أو استيراد CSV) — ليس عشوائيًا. |
| 3) التقييم | محرّك تقييم من 0 إلى 100 لكل عميل؛ من يتجاوز الحدّ (افتراضيًا 80) يتأهّل فقط. |
| 4) جهات الاتصال | استخراج عناوين البريد **المنشورة علنًا** على موقع الشركة + التحقق من صحتها. |
| 5) البحث | جلب نصّ موقع الشركة واستخراج تفاصيل حقيقية للتخصيص ("hooks"). |
| 6) الصياغة | كتابة عنوان + نص + سلسلة متابعة فريدة لكل عميل — بدون قوالب، بدون مبالغة. |
| 7) الإرسال | طابور إرسال مُنظَّم ضمن نافذة زمنية وحدّ يومي + تتبّع الفتح/النقر/الرد. |
| 8) لوحة التحكم | عرض المنتجات والحملات والعملاء والتقييمات والنِسَب. |

كل خطوة **تصفية** للتي بعدها، فلا يُبذَل جهد (أو تكلفة ذكاء اصطناعي) إلا على
العملاء الجيدين.

## 3. المكوّنات التقنية (Stack)

- **الواجهة:** Next.js 15 (App Router) + React 19 + TypeScript + TailwindCSS v4.
- **الخادم:** Next.js API Routes (نفس المشروع).
- **قاعدة البيانات:** PostgreSQL على **Supabase** (مجاني)، عبر Prisma ORM.
- **المصادقة:** NextAuth (Auth.js v5) — اسم مستخدم + كلمة مرور (مع خيار Google).
- **البريد:** Resend (أساسي) + SMTP/Brevo (احتياطي).
- **الذكاء الاصطناعي:** عبر مزودين متوافقين مع OpenAI: **Gemini** (أساسي) ثم
  **Groq** ثم **OpenRouter** (تبديل تلقائي عند الفشل أو نفاد الحصة).
- **الاستضافة:** Hostinger Business (تطبيق Node.js) — مع نشر تلقائي من GitHub.

---

## 4. طبقة الذكاء الاصطناعي

- **توجيه حسب المهمة:** كل مهمة (تحليل، تقييم، بحث، إيميل) لها قائمة نماذج مرتّبة.
  المهام البسيطة (التقييم) تستخدم النموذج الأرخص؛ التحليل والإيميل يستخدمان الأقوى.
- **تبديل تلقائي (Fallback):** يجرّب Gemini أولًا، فإن فشل أو نفدت الحصة ينتقل إلى
  Groq ثم OpenRouter — تلقائيًا. (الملف: `src/lib/ai/openrouter.ts` و `models.ts`)
- **منع التهيئة (Hallucination):** التعليمات صارمة — "لا تخترع حقائق"؛ إن تعذّر قراءة
  الموقع لا يُكتب شيء بدل اختلاق معلومة.
- **حصص يومية مجانية تكفي تمامًا:** Gemini ~1,500 طلب/يوم. لكل عميل ~3 نداءات
  (تقييم + بحث + إيميل)، أي يكفي لعشرات العملاء يوميًا بلا تكلفة.

---

## 5. محرك التقييم (Scoring)

نهج هجين: الذكاء الاصطناعي يقترح درجة لكل بُعد، والكود **يقصّها** ضمن حدّ أقصى لكل
بُعد فلا تتجاوز 100 أبدًا حتى لو هلوس النموذج:

| البُعد | الحد الأقصى |
|---|---|
| تطابق الصناعة | 30 |
| تطابق حجم الشركة | 20 |
| جودة الموقع | 10 |
| النشاط الاجتماعي | 15 |
| تطابق التقنية | 15 |
| تطابق نقطة الألم | 25 |

الدرجات تُخزَّن **مفصّلة** (لا مجرد مجموع) لتكون قابلة للتفسير والضبط. الحدّ الافتراضي
للتأهّل = 80 (قابل للتعديل لكل حملة). (الملف: `src/lib/scoring.ts`)

## 6. اكتشاف العملاء + جهات الاتصال + البحث

- **الاكتشاف:** عبر **Serper.dev** (مجاني 2,500 بحث/شهر) يحوّل استعلامات الـ ICP إلى
  نتائج بحث ويستبعد المنصّات الاجتماعية والأسواق. البديل الآمن: **استيراد CSV** (بدون
  أي مفتاح). (`src/lib/discovery/`)
- **جهات الاتصال:** جالب صفحات مهذّب يقرأ الصفحة الرئيسية وصفحات "اتصل بنا/من نحن"
  ويستخرج البريد **المنشور علنًا فقط** (لا تخمين). (`src/lib/contact/find.ts`)
- **التحقق من البريد:** فحص الصيغة + سجلات MX (مجانًا، بلا خدمة مدفوعة)، ووسم العناوين
  العامة مثل info@ كـ "خطرة". (`src/lib/email/validate.ts`)
- **البحث للتخصيص:** جلب نصّ الموقع وتلخيص خدماته واستخراج تفاصيل حقيقية تُستخدم في
  الإيميل. (`src/services/research-prospect.ts`)

> ملاحظة قانونية: تُجمَع فقط بيانات الأعمال المتاحة علنًا، مع احترام شروط الخدمة و
> robots.txt.

## 7. الإرسال والتتبّع والامتثال (Compliance)

- **طابور الإرسال:** عامل يرسل دفعة صغيرة في كل تشغيل، يحترم **النافذة الزمنية** و
  **الحد اليومي** لكل حملة، ويعيد المحاولة حتى 3 مرات. (`src/agent/dispatch.ts`)
- **التتبّع:** بكسل فتح موقَّع + إعادة توجيه نقر موقَّعة + رابط إلغاء اشتراك بنقرة
  واحدة (لا يمكن تزويرها — موقّعة بـ HMAC).
- **الامتثال مدمج:** كل رسالة تحمل **عنوانك البريدي** + رابط **إلغاء الاشتراك** +
  ترويسات `List-Unsubscribe`. (`src/lib/email/compliance.ts`)
- **قائمة الحظر (Suppression):** الارتدادات والشكاوى وإلغاء الاشتراك تُضاف تلقائيًا،
  ويُفحَص العنوان مرّتين قبل أي إرسال — فلا تُرسَل رسالة لمن انسحب أبدًا.
- **Webhook من Resend:** يحدّث حالات التسليم/الفتح/النقر/الارتداد/الشكوى.

---

## 8. الوكيل الذاتي (الأتمتة)

- يعمل لكل حملة نشطة، **على دفعات** (حتى يناسب مهلة الاستضافة المشتركة).
- المسار **قابل للاستئناف**: حالة كل عميل/رسالة محفوظة، فتشغيل الكرون المتكرر يُكمل
  من حيث توقّف بأمان (لا تكرار).
- يُشغَّل عبر **Cron** (كل ~10 دقائق) يطرق نقطتين محميّتين بـ Bearer:
  - `POST /api/agent/run` → اكتشاف → تقييم → بحث → صياغة (إلى قائمة الموافقة).
  - `POST /api/agent/dispatch` → إرسال الموافق عليها ضمن الحدود.
- يمكن أيضًا التشغيل اليدوي من صفحة الحملة بزر "تشغيل الآن".

## 9. الشاشات (لوحة التحكم)

- **Dashboard:** قائمة الموافقة أولًا (الإجراء اليومي)، مع النِسَب والمسار (Funnel).
- **Products:** إنشاء منتج، زر **Analyze**، عرض الـ ICPs والزوايا، إطلاق حملة.
- **Campaigns:** إنشاء/تشغيل حملة، رؤية العملاء والإحصائيات، استيراد CSV.
- **Leads:** كل العملاء مع تقييمهم وحالتهم + استيراد CSV.
- **Approvals:** مراجعة المسودات والموافقة/الإلغاء بنقرة.
- **Settings:** مفاتيح الـ API، هويات المُرسِل، قائمة تحقّق التسليم.

---

## 10. قاعدة البيانات (نموذج البيانات)

~20 جدولًا، العمود الفقري هو **Lead** بآلة حالة واضحة:
`DISCOVERED → SCORED → QUALIFIED → CONTACT_FOUND → RESEARCHED → DRAFTED → QUEUED
→ CONTACTED → REPLIED → CONVERTED`.

أهم الجداول: المستخدمون، المنتجات، التحليل، ملفات العملاء (ICP)، الحملات، العملاء،
جهات الاتصال، التقييمات، البحث، الرسائل + أحداثها، قائمة الحظر، هويات المُرسِل،
المفاتيح (مشفّرة)، عدّادات الاستخدام، سجل التدقيق، وتشغيلات الوكيل.
- منع التكرار عبر الدومين، أحداث البريد سجل لا يُعدَّل، الأسرار مشفّرة.

---

## 11. الأمان

- عزل بيانات كل مستخدم + فحص الملكية في كل عملية تعديل.
- تحقّق من المدخلات (zod) عند كل حدود.
- تشفير الأسرار (مفاتيح المستخدمين) بـ **AES-256-GCM**.
- حدود/حصص يومية (anti-abuse)، نقاط الكرون محميّة بـ Bearer، روابط عامة موقّعة.
- سجل تدقيق لكل إجراء، وحماية من إعادة التوجيه المفتوح في تتبّع النقر.

---

## 12. المفاتيح والإعدادات (لكل مستخدم)

- كل مستخدم يدخل **مفاتيحه الخاصة** من **Settings → API keys**: Gemini, Groq,
  OpenRouter, Resend, Serper, SMTP. تُخزَّن **مشفّرة** وتُستخدم لحملاته فقط.
- إن لم يضع المستخدم مفتاحًا، يستخدم النظام المفتاح الافتراضي (إن وُجد).
- بيانات الإقلاع الحساسة (الاتصال بقاعدة البيانات، مفتاح التشفير، أسرار المصادقة)
  مكتوبة في `src/lib/config.ts` و `prisma/schema.prisma` — لذلك **يجب إبقاء
  المستودع Private**.

## 13. تعدد اللغات (عربي / إنجليزي + RTL)

- مبدّل لغة (EN / ع) في الشريط العلوي وصفحات الدخول والهبوط.

## 15. التكلفة والحدود

- **التكلفة الهامشية ≈ 0$/شهر**: نماذج ذكاء اصطناعي مجانية + Resend مجاني (100/يوم)
  + Supabase مجاني + Serper مجاني (2,500/شهر).
- الحد اليومي للإرسال = 50 (هيّئ الدومينات الجديدة ببطء: 5–10/يوم في البداية).
- على دومين جديد: وثّق SPF/DKIM/DMARC في Resend قبل الإرسال الجاد.

---

## 16. ما الذي يتبقّى (تحسينات مستقبلية)

1. التحقّق من توقيع Webhook الخاص بـ Resend (Svix).
2. احترام المنطقة الزمنية لكل حملة في نافذة الإرسال (حاليًا UTC).
3. توليد/إرسال **سلاسل المتابعة** (مُصمَّمة في القاعدة لكن لم تُفعَّل بعد).
4. حلقة تعلّم: ترجيح التقييم حسب الزوايا/الـ ICP التي حقّقت ردودًا.
5. اكتشاف اللغة تلقائيًا من المتصفّح عند أول زيارة.

### الخلاصة
أضف منتجًا → Analyze → أطلق حملة → استورد عملاء أو شغّل الـ pipeline → راجع
المسودات في Approvals ووافق → يُرسِل النظام بهدوء وانضباط ويتتبّع النتائج. كل ذلك
بلغتين، وبتكلفة شبه صفرية، مع حماية كاملة للسمعة والامتثال.
